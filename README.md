## 它是什么

一个跑在你自己电脑或 VPS 上的服务。启动之后打开浏览器，在网页里配好角色、模型和号码，
角色就会在 iMessage 里和你（或者别人）真的聊起来 —— 拆成好几条气泡发、打字有停顿、
会已读不回、会发语音条、会现画一张图，也会隔一阵子没人说话就自己开口。

它**不提供**任何 AI 模型或 iMessage 线路，这两样要你自己准备。

## 能做什么

**聊天本身**

- 一条回复拆成多条气泡，按字数算打字延迟；对方连发几条会合并成一轮再回
- 收到图片会先识图、收到语音条会先转写，然后连着文字一起发给模型
- 已读、不回、撤回、贴 emoji 回应、气球烟花特效、链接卡片、位置卡片，都是 iMessage 原生的玩法
- 发**真的语音条**（MiniMax / ElevenLabs / GPT-SoVITS），现画图发过去，从图库按标签随机发表情包
- 答不上来的时候先联网搜一下再回话

**记住事情**

- **记忆**：聊够轮数自动总结，靠向量检索取回相关的那几条
- **备忘录**：一份不断覆盖的清单（谁的生日、约了什么）
- **日记**：第一人称写，永不清空

**不只是短信**

- **线下模式**：坐下来演一段剧情，角色气泡在左你的在右，能重 roll、能编辑、能自由改总结
- **Instagram**：给角色一个主页，会自己发帖发快拍，也会来给你点赞留言（单开一个端口）
- **主动消息**：没人说话时隔一阵子自己找你，随机时间或让模型自己判断，带勿扰时段
- **查手机**：翻角色自己的手机 —— 信息、通讯录、通话、购物、外卖、浏览器、钱包、今天的活动轨迹、收藏夹，还能自己加 App
- **小剧场**：主线之外的番外，让模型写成一份可以直接打开的 HTML 页面
- **共感娃娃**：手机塞进玩偶里，抱一下角色就知道 —— 传感器用手机上的 phyphox，
  不用买硬件；抱了多久、抱得多紧都能进那句提示。后端在自己电脑上就让它去读手机，
  在 VPS / 小手机上就让手机推过来

**配起来不难**

- **快速配置卡片**：新用户第一次打开会自动弹出来，一步一步问，填完就能跑
- **Uranus 助手**：右下角那颗气泡，不知道某个开关在哪、报错缺什么，问它
- **多角色 / 多号码**：一个角色绑一条号码，各自独立的人设、模型和记忆，同时在线
- 完整备份（整个数据目录打包）、只导配置的搬家包、传到缤纷云或 GitHub 的云备份
- 手机上直接发 `/help` 看指令：清上下文、切模型、立刻出图、立刻总结、重启……

## 快速开始

### Windows

装好 [Node.js](https://nodejs.org/) 20 或更新的版本，然后双击 **`启动.bat`**。

它自己会检查依赖、装依赖、构建前端、起服务、开浏览器。之后每次也是双击这一个文件。

- 只占一个端口 **8787**，API 和页面都在这；Instagram 那一页单独占 **6873**
- 想改端口：`set PORT=8888` 之后再运行
- 改了前端代码要重新构建：再双击一次 `启动.bat` 就行，它检测到产物过期会自己
  先构建一遍（想手动来就是 `npm run build`）。项目**没有**热更新的开发模式
- 升到新版本：双击 **`更新.bat`**。旧文件自动备份到 `.update-backup\`，依赖没变
  就不重装，`data/` 不碰。**撞上你自己改过的文件它会停下来报错，不覆盖**

### Linux / VPS

```bash
git clone https://github.com/nikonotnicotine/Uranus_Imessage.git
cd Uranus_Imessage
npm install
npm run build
npm start
```

打开 `http://localhost:8787`。想常驻用 systemd，参考 `scripts/` 下的启动脚本。

### 安卓手机

一台闲置的安卓机（插着电、连着 Wi-Fi）就能当服务器，24 小时在线且不花钱。装 Termux
之后步骤和 Linux 差不多，但有两个依赖要先删掉（`ffmpeg-static` 和
`@spectrum-ts/imessage-local` 在安卓上装不上），还要关掉安卓那几层后台杀进程的机制。

完整步骤见[图文教程](https://docs.qq.com/doc/DVnFncG9Tc05kdFZY)。

> 聊天用的苹果设备和这台安卓**没有任何直接连接** —— 安卓只是跑服务的那台机器。

### 第一次打开之后

先是**登录页**，第一次用默认的 `Uranus` / `Uranus` 进去，进去之后会让你立刻
换成自己的一组（密码不少于 8 位、至少一个大写字母）。这一步不能跳 ——
不改的话除了改账号密码什么都干不了。之后想改或者退出登录，在**控制台 · 账号**那一节。

> 密码忘了：打开 `data/auth.json`，把 `password` 那行的值改成 `null`，存盘就生效
> （不用重启），账号密码回到默认的 `Uranus` / `Uranus`。

然后界面会自动弹出**快速配置卡片**，跟着走完就能收发消息。要点是三件事：

1. **连接** —— 填一个服务商源的 API 地址和密钥，把模型加进来，给它勾上「聊天」分类
2. **iMessage** —— 填 Photon 的凭据，登记自己的手机号，拿到一条线路号码
3. **角色** —— 起个名字、写人设、选刚才那个聊天模型、绑上那条号码

角色详情页最上面那行会写「在线 / 未上线」，写着在线就可以去手机上发消息了。
卡在哪一步就问右下角的 Uranus，或者看 [Niki 写的图文教程](https://docs.qq.com/doc/DVnFncG9Tc05kdFZY)。

### 在国内的话

程序自己不带代理，所有请求都直连出去。天气、Photon（iMessage 桥接）、音乐、国内的中转站
直连都通；**Instagram 和 DuckDuckGo 搜索直连不通**，要用的话在这台机器上开全局代理：

- Clash 这类客户端请开 **TUN 模式**（虚拟网卡）。只开「系统代理」那个开关不够 ——
  后台用的 Node 不认系统代理，请求照样直连出去
- 联网搜索也可以换成 Tavily / Brave，国内直连就通

## 界面分区

| 分区 | 管什么 |
|---|---|
| **连接** | API 地址、密钥、模型清单和分类；语音合成的三家凭据 |
| **角色** | AI 演谁。人设、用哪个模型、开哪些功能、绑哪条号码，一个角色一整套 |
| **用户** | 和 AI 说话的人是谁（提示词里的 `{{user}}`） |
| **预设** | 提示词按什么顺序拼、生成参数给多少、正则怎么改写输出。线上线下各一批 |
| **世界书** | 设定条目，常驻的每轮都发，其余靠关键词触发 |
| **图库** | 图生图的参考图、按标签分组的表情包 |
| **记忆库** | 三样长期记忆的内容和设置 |
| **线下模式** | 线下剧情：演、切换、重 roll、改总结 |
| **上下文** | 所有会话的对话记录存档，以及最后一次真正发给模型的那份完整提示词 |
| **查手机** | 一台模拟的 iPhone，翻角色手机里的东西；一键生成、同步到私聊 / 日记 |
| **小剧场** | 番外模板、生成好的 HTML 成品、续写和收藏 |
| **Instagram** | 角色主页的内容和总设置 |
| **发送** | 发送节奏（气泡怎么拆、停多久）和防相亲 |
| **iMessage** | 一个项目 = 一条号码，凭据填在这儿 |
| **控制台** | 实时日志、登录账号、重启服务、清缓存、检查更新、备份 / 恢复、云备份、自定义 CSS、插件 |

## 目录结构

```
Uranus_Imessage/
├── client/          前端（React + Vite + Tailwind）
│   └── src/panels/  一个分区一个文件
├── server/          后端（Node + Express）
│   └── src/         config / prompt / imessage / memory / offline / instagram …
├── scripts/         启动器、图标生成、各模块的离线自检
├── assets/          内置壁纸和内置预设（新用户的开箱默认值）
├── data/            ← 你的全部数据，不进仓库
│   └── plugins/     装了的插件，一个插件一个文件夹
├── 启动.bat          日常用这个
└── 更新.bat          升到新版本用这个（自动备份，撞上你的改动会停下来）
```

`data/` 整个文件夹就是唯一的备份单元 —— 拷走它，配置和聊天记录一起备份了。
一类一个文件夹、一个条目一个文件，所以也可以单独拷一个角色或一本世界书给别人。
想放到别的盘，设环境变量 `URANUS_DATA_DIR` 指过去。

## 数据与隐私

**所有东西都在你自己机器上。** 项目没有任何服务器，不会把配置、聊天记录或密钥传去任何地方 ——
唯一的出网请求就是你自己填的那些第三方服务（模型 API、Photon、TTS、搜索、天气、云备份）。

密钥单独存在 `data/data.config.json`，不进 `config.json`、不进导出的搬家包，
完整备份也要显式勾上「含密钥」才会带。`data/` 已经在 `.gitignore` 里。

**控制台要登录才能打开**，`/api/` 全部在门后面。这一条对 VPS 特别要紧：那种环境里
`0.0.0.0` 是默认，安全组一开就是全端口对全网，没有门的话任何知道 IP 的人都能看到
你的密钥、手机号和聊天记录。密码存的是 scrypt 哈希加随机盐（`data/auth.json`），
明文一个字节都不落盘。会话是一条 30 天的签名 cookie，服务端不存会话表，
所以重启不掉线，而改密码会让所有别的设备掉线。

## 插件

控制台左边导航轨上「插件」那一格：上面是插件市场，下面是装好的插件和开关。
插件装在 `data/plugins/<插件id>/`。

[插件市场](https://github.com/nikonotnicotine/uranus-plugins)是一份**链接目录** ——
那个仓库里没有插件代码，只有清单。控制台把它渲染成卡片，点「去下载」在新标签页打开
作者的仓库，下载 zip 回来导入。控制台不会替你下载任何东西，后端也没有
「从 URL 安装」那条路。目录由后端代拉并缓存（`raw.githubusercontent.com` 国内多半
连不上，而后端那台机器一般已经为了调模型 API 配好出网了）；想换成别的目录源，
设 `URANUS_PLUGIN_MARKET` 环境变量。

**插件能做的事和控制台自己一样多** —— 它能读写你的聊天记录和角色设定、看到你填的
API 密钥、替你调用任何接口。装一个插件 ≈ 让一个陌生人在你的服务器上跑代码。
市场收录前会看一遍代码，但那不是安全审计，也管不到作者之后又改了什么。
**只装你信得过的作者写的东西。**

出事了的三条路：

- 插件总开关默认**关着**，装进来和同意让它跑是两件事；
- 插件把界面写崩了：网址后面加 `?noplugins`，这一次什么插件都不加载，开关照样点得到；
- 一个插件报错只禁它自己，别的插件和控制台照常跑。

**插件可以有自己的设置。** 比如一个 TTS 插件要你填接口地址和密钥，一个天气插件要你选城市 ——
插件作者在他的 `manifest.json` 里声明要哪些项，控制台自动渲染成表单，你在那个插件的「设置」里填。
有哪些项、叫什么、什么类型，都是插件作者定的。改完要刷新页面才生效。

配置跟着备份走，**包括里面填的密钥，而且不勾「含密钥」也会带** —— 不这样的话换台机器
每个插件都要重填一遍。代价是备份包里会有插件的 key，别随便发人。

插件市场那份目录带一张下架名单。装了名单上的插件，插件分区最上面会亮红色警告，
写清楚为什么下架 —— 安全原因的那档还会提示你换掉 API 密钥。审核总会漏，召回不能漏。

插件跟着备份走，但**只带清单不带代码**：打包时只带 `installed.json` 和各插件的
`manifest.json`。一份备份搬到别人机器上恢复，不该等于在那台机器上自动落下一批
第三方可执行代码 —— 恢复之后照着清单去市场重新下载。

想自己写一个：先看[怎么写一个 Uranus 插件](https://github.com/nikonotnicotine/uranus-plugins/blob/main/WRITING-PLUGINS.md)，
再照着[示例插件](https://github.com/nikonotnicotine/uranus-plugin-hello)的结构改。上架规则和提交流程在市场仓库的 README 里。

## 技术栈

Node.js 20+ / Express 后端，React 18 + Vite 5 + Tailwind 3 前端，npm workspaces 单仓。
生产环境后端直接 serve 前端产物，只占一个端口。数据全部落在本地文件，没有数据库。

模型接口默认走 OpenAI 兼容协议（服务商源的「自定义」类型，中转站都是这种）；
新建服务商源时也能直接选 OpenAI、Google Gemini、Google Vertex AI、Anthropic Claude
四家官方接口，后三家打的是各自的原生接口。Vertex 那条密钥粘一整份 GCP 服务账号 JSON
就行（express 模式的 API key 也认），同一个源下 Gemini 和 Vertex 上托管的 Claude 都能用。
听音那条走 Gemini 原生接口。
生图还能选 NovelAI（只能画图），中文画面描述会先借聊天模型翻成英文 tag。
iMessage 走 Photon / Spectrum。

## 想再深入一点

**代码里的注释就是文档。** 每个模块的文件头都写着它为什么这么设计、踩过什么坑、
哪些地方动了会出事 —— 提示词怎么拼看 `server/src/prompt.js`，记忆库怎么打分看
`memorystore.js`，主动消息怎么算时间看 `proactive.js`，线下模式的存档结构看
`offline.js`，备份为什么不带密钥看 `backup.js`。遇到具体问题时直接搜关键词。

各模块都有不联网、不碰 `data/` 的离线自检：

```bash
node scripts/test-memory.mjs
node scripts/test-assistant.mjs
node scripts/test-auth.mjs
```
