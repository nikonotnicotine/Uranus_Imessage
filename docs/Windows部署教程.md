# Windows 部署教程

在自己的 Windows 电脑上跑 Uranus iMessage。

**核心就一句：装好 Node.js，双击 `启动.bat`。** 剩下的它自己搞定——装依赖、构建前端、起服务、开浏览器。

下面这份是给「双击之后没成功」和「想搞明白它在干什么」的人看的。

> 想让服务 24 小时在线、关电脑也不断？那要用云服务器，看 [VPS 部署教程](VPS部署教程.md)。
> Windows 这条路适合先在自己电脑上试起来，或者电脑本来就常开着。

## 1. 三步跑起来

### 第 1 步：装 Node.js

去 [nodejs.org](https://nodejs.org/) 下载 **LTS 版本**（要 20 或更新，现在下到的是 22 或 24，都行）。

下完双击安装包，**一路下一步**，什么都不用改。装完**重启一下电脑**，或者至少把已经开着的命令行窗口全关掉——不然它找不到新装的 Node。

**验证装好了**：按 `Win + R`，输入 `cmd` 回车，在弹出的黑窗口里敲：

```bash
node -v
```

出现 `v22.14.0` 这样的版本号就成了（数字不一定一样，**20 以上就行**）。

**如果报 `'node' 不是内部或外部命令`**：说明装完没重启，或者装的时候取消了「Add to PATH」那个勾。重启电脑再试；还不行就重装一遍，安装过程别取消任何默认勾选。

### 第 2 步：把项目下载下来

**方法一：直接下 ZIP（推荐，不用装 git）**

打开 [github.com/nikonotnicotine/Uranus_Imessage](https://github.com/nikonotnicotine/Uranus_Imessage)，点绿色的 **Code** 按钮 → **Download ZIP**。

下完**右键解压**到一个你记得住的地方，比如 `D:\Uranus`。

> ⚠️ **别放在 C 盘的「下载」「桌面」「文档」里**，也别放在带 OneDrive 同步的目录里。OneDrive 会一边同步一边锁文件，`npm install` 装到一半会失败。
>
> ⚠️ **路径里别有特殊符号**。中文和空格现在没问题，但 `&`、`%`、`!` 这类会让批处理解析出错。`D:\Uranus` 这种最稳。

**方法二：用 git**（以后更新方便，见 [5.1](#51-更新到新版本)）

装个 [Git for Windows](https://git-scm.com/download/win)，然后在你想放的位置右键 → **Open Git Bash here**，敲：

```bash
git clone https://github.com/nikonotnicotine/Uranus_Imessage.git
```

### 第 3 步：双击 `启动.bat`

进到解压出来的文件夹，找到 **`启动.bat`**，**双击**。

会弹出一个黑窗口，依次打印：

```
  ======================================
    Uranus iMessage
  ======================================
  控制台在 8787：API 和页面都在这
  Instagram 单独在 6873：打开就是 IG，同一个后端

  [1/4] Node.js v22.14.0
  [2/4] 第一次运行，安装依赖，要几分钟，别关窗口...
```

**`[2/4]` 这一步要 2~5 分钟**，在下载几百个软件包。**别关窗口**，也别以为它卡死了。

装完继续走 `[3/4]` 查端口、`[4/4]` 构建前端，最后打印：

```
  --------------------------------------------
    控制台     http://localhost:8787
    Instagram  http://localhost:6873
    停止       在本窗口按 Ctrl+C
  --------------------------------------------
```

**浏览器会自己打开控制台页面。** 看到登录页就成了。

> **这个黑窗口不能关。** 关掉服务就停了。想停服务就在窗口里按 `Ctrl + C`。
>
> 以后每次要用，还是双击这同一个 `启动.bat`。第二次开就快了，依赖不用重装。

## 2. 第一次打开控制台

### 2.1 登录并改密码

默认账号密码都是 `Uranus`。

进去之后会**强迫你改密码**（跳不过去），要求**至少 8 位，至少一个大写字母**。不改的话除了改密码什么操作都做不了。

### 2.2 填配置

界面会自动弹出**快速配置卡片**，跟着走完就行。要点是三件事：

1. **连接** → 填模型 API 地址和密钥，把要用的模型加进清单，勾上「聊天」分类
2. **iMessage** → 填 Photon 的凭据，登记自己的手机号，拿到一条线路号码
3. **角色** → 起名字、写人设、选刚才那个聊天模型、绑上那条号码

角色详情页最上面会写「在线 / 未上线」。**写着在线就可以去手机上发消息了。**

卡在哪一步就问右下角那颗气泡（Uranus 助手），或者看 [Niki 的图文教程](https://docs.qq.com/doc/DVnFncG9Tc05kdFZY)。

### 2.3 在国内要配代理

去**控制台 · 代理**。改完当场生效，不用重启。

**默认已经勾好了 Instagram 和天气**——这两类数据源在国内直连不通，保持原样。

- **Photon（iMessage 桥接）实测直连就通，不用勾**
- **模型 API** 打的是你自己买的中转站，多半直连通，套上代理反而慢
- 只能填 `http://` 或 `https://`，**`socks5://` 用不了**。Clash、v2rayN 那类客户端一般同时开着一个 http 端口（默认 **7890** / **10809**），用那个
- 面板旁边有「测试连通」和「测一下直连」两个按钮，**两个都点**：都通说明这个源不需要代理（把勾取消）；都不通说明你电脑出网本身有问题

> 💡 **本机跑的好处**：你电脑上的科学上网客户端开着的话，代理地址填 `http://127.0.0.1:7890` 就行，不用像 VPS 那样另外找一个代理。

## 3. 启动器在干什么

看不懂可以跳过，但知道了排错会顺很多。双击之后它按顺序做四件事：

| 步骤 | 做什么 | 出问题看 |
|---|---|---|
| `[1/4]` | 查 PATH 上有没有 Node，打印版本 | [4.1](#41-提示找不到-nodejs) |
| `[2/4]` | 查 `node_modules` 里几个关键包在不在，缺了就跑 `npm install` | [4.2](#42-装依赖失败) |
| `[3/4]` | 查 8787 和 6873 有没有被占，占了就问你要不要结束那个进程 | [4.3](#43-端口被占用) |
| `[4/4]` | 对比源码和 `client/dist` 的时间戳，产物旧了就自动 `npm run build` | [4.4](#44-构建失败) |

然后启动服务，进一个**守护循环**——控制台上那个「重启服务」按钮和聊天里的 `/重启` 指令靠这个才能用。

**两个端口的分工**：

| 端口 | 是什么 |
|---|---|
| **8787** | 控制台，所有配置都在这。API 也在这 |
| **6873** | Instagram 页面（角色的主页） |

两个端口是**同一个进程**，共用同一份前端产物，只是按请求打在哪个端口上决定回哪个页面。

**为什么服务已经在跑时双击不会重复启动**：它会先探一下 8787，发现上面就是本项目就直接开浏览器，然后提示你「要重启的话先去原来那个窗口按 Ctrl+C」。

## 4. 常见问题

### 4.1 提示找不到 Node.js

窗口里出现：

```
  [X] Node.js not found. Install v20+ from https://nodejs.org
```

**原因**：Node 没装，或者装完没重启（PATH 还没生效）。

**先重启电脑**再双击一次。还不行就打开 `cmd` 敲 `node -v` 确认——报「不是内部或外部命令」就重装 Node，安装过程别取消任何默认勾选。

### 4.2 装依赖失败

`[2/4]` 那一步红字报错。**按报错内容对号入座**：

**报 `ETIMEDOUT` / `ECONNRESET` / 卡着不动**——网络问题，换国内源。打开 `cmd`，`cd` 到项目目录（或者在项目文件夹里按住 `Shift` 右键 → **在此处打开 PowerShell 窗口**），敲：

```bash
npm config set registry https://registry.npmmirror.com
```

然后重新双击 `启动.bat`。

**报 `EPERM` / `operation not permitted`**——文件被锁了。三个可能：

- **杀毒软件**在扫 `node_modules`。把项目目录加进白名单
- **OneDrive 在同步**。把项目移出 OneDrive 目录
- 上次装到一半留了残留。删掉项目目录里的 `node_modules` 文件夹，重新双击

**报 `EACCES` / 权限相关**——右键 `启动.bat` → **以管理员身份运行** 试一次。

**报 `gyp` / `Visual Studio` / `python`**——某个依赖要编译。这个项目的依赖里没有必须编译的，出现这个一般是 Node 版本太老，装 20 以上的重来。

**都不是上面这些**：把报错**从 `npm ERR!` 开头往下截全**发到群里问（QQ 群 `1125033956`）。

### 4.3 端口被占用

窗口里出现：

```
  [!] 端口 8787 被别的程序占用：xxx.exe（PID 1234）
      结束它再继续？  Y=结束   N=退出
```

**先看占用者是谁**：

- **写着「已经跑着本项目了」**——你之前开过一次没关。按 `Y` 结束，或者按 `N` 退出、去找那个旧窗口
- **写着别的程序名**——按 `N` 退出，先想清楚那是什么。有些开发工具、代理软件也用 8787

**不想结束别人的进程**，就换个端口跑。在项目文件夹里按住 `Shift` 右键 → **在此处打开 PowerShell 窗口**，敲：

```bash
$env:PORT=8888; node scripts/launch.mjs start
```

（用 `cmd` 的话是 `set PORT=8888` 然后 `node scripts\launch.mjs start`）

**Instagram 那个端口（6873）腾不出来不影响主功能**——它会提示一句然后照常启动，只是 IG 页打不开。

### 4.4 构建失败

`[4/4]` 那一步报错。**先试一次**手动构建看完整报错，在项目目录的 PowerShell 里：

```bash
npm run build
```

**报缺模块**——依赖没装全，删掉 `node_modules` 重新双击 `启动.bat`。

**报路径过长**——项目放得太深了。挪到 `D:\Uranus` 这种短路径下。

### 4.5 浏览器没自动打开

服务其实起来了，只是浏览器没弹。**手动打开**：

```
http://localhost:8787
```

### 4.6 忘了控制台密码

用记事本打开项目目录下的 `data\auth.json`，找到 `"password"` 那一行，把值改成 `null`（**只改这一行**）：

```json
"password": null,
```

存盘。**刷新控制台页面**就生效（不用重启服务），密码回到默认的 `Uranus`，进去后重新设一个。

> 那个文件开头写了这句话提醒你怎么做，改的时候看一眼就行。

### 4.7 关掉窗口之后服务就停了

**这是正常的。** 那个黑窗口就是服务本身，关掉等于停止。

想让它一直在后台跑、不占一个窗口，看 [5.3](#53-让它开机自启后台常驻)。想彻底不受自己电脑影响，用 [VPS 部署](VPS部署教程.md)。

### 4.8 电脑睡眠后角色不回消息了

**这是正常的**——电脑睡了服务也跟着停了。

**改设置**：`Win + I` → **系统** → **电源和电池** → **屏幕和睡眠**，把「使计算机进入睡眠状态」设成**从不**。

笔记本注意还有一项「合上盖子时」的设置，在**控制面板 → 电源选项 → 选择关闭盖子的功能**里改成**不采取任何操作**。

> ⚠️ 长期不睡眠对笔记本电池不友好。要 24 小时在线的话，还是 [VPS](VPS部署教程.md) 更合适。

### 4.9 语音条发不出去

项目自带一份 ffmpeg，正常不用管。真出问题的话，日志里会写找不到 ffmpeg——把报错发到群里。

### 4.10 还是搞不定

把这些一起发到 QQ 群 `1125033956`：

1. **`启动.bat` 窗口里的完整报错**（从第一行红字往下全截，别只截最后一句）
2. Node 版本，在 PowerShell 里敲：

```bash
node -v
```

3. 项目放在哪个路径

**发之前把里面的密钥、手机号打码。**

## 5. 进阶用法

### 5.1 更新到新版本

**如果你是下 ZIP 装的**：重新下一份 ZIP，解压到**新文件夹**，然后把**旧文件夹里的 `data` 整个文件夹**拷进新的。

> ⚠️ **`data` 就是你的全部数据**——配置、密钥、聊天记录、角色、图片、记忆都在里面。换版本、搬电脑，只要这一个文件夹跟着走就行。

**如果你是 git clone 装的**，在项目目录的 PowerShell 里：

```bash
git pull
```

然后双击 `启动.bat`——它检测到源码比产物新，会自己重新构建。

### 5.2 手动启动（不用 .bat）

在项目目录的 PowerShell 里：

```bash
npm run build
```

```bash
npm start
```

**区别**：这么起的话控制台上那个「重启服务」按钮**不能用**——那个按钮靠 `启动.bat` 的守护循环实现，手动启动没人接盘，后端会拒绝重启请求并说明原因。

日常还是双击 `启动.bat` 省事。

### 5.3 让它开机自启、后台常驻

**先说清楚**：Windows 上做这个没有很干净的办法，而且**电脑睡眠或关机它照样会停**。真要 24 小时在线，[VPS](VPS部署教程.md) 才是对的路。

要做的话，最简单的是**扔进「启动」文件夹**：

按 `Win + R`，输入 `shell:startup` 回车，会打开一个文件夹。把 `启动.bat` 的**快捷方式**（右键 → 显示更多选项 → 创建快捷方式，然后把快捷方式拖过去）放进去。

下次开机登录后它会自动跑起来，还是会有那个黑窗口。

**不想看到窗口**的话，用「任务计划程序」建一个任务，触发器选「登录时」，操作选那个 `.bat`，勾上「不管用户是否登录都要运行」。这套配起来比较绕，不熟悉的话不如就留着窗口。

### 5.4 改端口

**临时改一次**，PowerShell：

```bash
$env:PORT=8888; node scripts/launch.mjs start
```

**永久改**：新建一个 `我的启动.bat`，内容：

```bat
@echo off
cd /d "%~dp0"
set PORT=8888
set URANUS_IG_PORT=6874
node scripts\launch.mjs start
pause
```

以后双击这个文件。

**可用的环境变量**：

| 变量 | 作用 |
|---|---|
| `PORT` | 控制台端口，默认 `8787` |
| `URANUS_IG_PORT` | Instagram 端口，默认 `6873`。设成 `off` 就不开这个端口 |
| `URANUS_NO_BROWSER=1` | 启动后不自动开浏览器 |
| `URANUS_DATA_DIR` | 把数据目录挪到别处，见 [5.5](#55-把数据放到别的盘) |
| `URANUS_PROXY` | 出网代理，和控制台里填的等价 |

### 5.5 把数据放到别的盘

数据默认在项目目录下的 `data\`。想挪到别的盘（比如项目在 C 盘、数据放 D 盘）：

```bat
@echo off
cd /d "%~dp0"
set URANUS_DATA_DIR=D:\UranusData
node scripts\launch.mjs start
pause
```

**第一次启动它会自己把目录建出来。** 已经有数据的话，先把原来的 `data` 文件夹整个拷到新位置再改。

> 💡 项目自带的素材（默认壁纸、开箱预设）在 `assets\` 里，那是只读的、跟代码走，**不受这个变量影响**。

### 5.6 手机上访问电脑跑的服务

同一个 Wi-Fi 下，手机浏览器打开 `http://电脑的局域网IP:8787`。

**查电脑 IP**，PowerShell：

```bash
ipconfig
```

找「无线局域网适配器 WLAN」下面的 **IPv4 地址**，一般是 `192.168.x.x`。

**打不开的话**是防火墙拦了。第一次跑 Node 时 Windows 会弹一个「允许访问网络」的框，当时点了「取消」就会这样。去**控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙**里找 Node.js，把「专用网络」勾上。

> ⚠️ **别为了外网访问去路由器上做端口映射。** 那等于把你的 API 密钥和全部聊天记录挂到公网上，而默认密码是公开写在文档里的。要在外面访问的话装个 [Tailscale](https://tailscale.com/download)，手机和电脑登同一个账号，用它给的 `100.x.x.x` 地址访问——不用开任何端口。

---

**最后一句**：所有数据都在项目目录的 `data\` 文件夹里。
只要这个文件夹在，换电脑、重装系统都能原地复活——拷过去就行。
